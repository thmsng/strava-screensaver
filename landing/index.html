What you get

Ghost races by area

The map flies to one part of your running history at a time and replays up to 8 runs side by side at their real relative pace.

Colour by what matters

Distance by default. Switch to year, pace or road vs trail, or let it cycle through all of them.

Stats and captions

Total distance, runs, this year, longest run and more, plus date, name, distance and pace for each runner.

Made for the desktop

A calm replay with captions and stats tucked on the right, so your desktop icons stay clear. No background process needed.

Set up

About five minutes, mostly the one-time Strava setup.

  1. Download and unzip

    Download StravaScreensaver-win64.zip and extract it anywhere (right-click, Extract All).

  2. Run the installer

    Open the extracted folder and double-click Install.cmd. It copies the app to %LOCALAPPDATA%\StravaScreensaver, prepares the wallpaper folder, adds a quick refresh at login (it fetches new runs, then exits) and opens the settings. It does not change your screensaver. No administrator rights needed.

    The app isn't code-signed, so Windows SmartScreen may warn you. Choose More info, then Run anyway.

  3. Create your Strava API app (one time)

    Strava only lets an app read your runs through an API app you own. It's free:

    • Open strava.com/settings/api and create an application.
    • Any name and category. Website: http://localhost
    • Authorization Callback Domain: localhost
    • Copy the Client ID and Client Secret.

  4. Connect and sync

    In the settings window paste the Client ID and Secret and click Save & connect to Strava. Approve access in your browser. Your runs sync in a few seconds (longer for a very long history).

  5. Check the preview

    Click Preview in the settings to see your runs animate fullscreen (press any key to leave), and pick your map style and colours. Then continue to Lively below.

Your client secret and runs are stored only on your PC, in %APPDATA%\strava-screensaver. Reopen the settings any time by running %LOCALAPPDATA%\StravaScreensaver\StravaScreensaver.exe.

Put it on your desktop with Lively

Windows has no built-in live wallpapers, so use the free Lively Wallpaper app. The wallpaper is a small self-contained folder with your runs inside. Nothing needs to run in the background.

  1. Connect Strava and export

    Finish the install steps above so your runs are synced. The installer already creates the wallpaper folder; click Export wallpaper in the settings (section 4) any time to see its location or refresh it.

    It lives at %APPDATA%\strava-screensaver\wallpaper\index.html. After that it refreshes itself whenever new runs sync or you change a setting. A quick refresh runs each time you log in (a few seconds, then it exits) to fetch new runs.

  2. Install Lively Wallpaper

    Get it free from the Microsoft Store or rocksdanister.github.io/lively.

  3. Add the wallpaper

    In Lively click + Add Wallpaper (top left), then Browse, and pick the index.html from the folder above. Tip: paste %APPDATA%\strava-screensaver\wallpaper into the file dialog's address bar to jump there. Name it "Strava runs" and click OK.

  4. Set it

    Click the new tile in your library to apply it. It now plays behind your desktop icons.

Wallpaper mode replays slowly and puts the captions, legend and stats on the right, so your desktop icons on the left stay clear. Turn any of them off in the settings.
New runs show up after your next login (or click Export wallpaper in the settings), once Lively restarts or you re-apply the wallpaper.
Advanced: live wallpaper server (always up to date, one background process)

If you'd rather have Lively load a web address that is always current, install with .\Install.ps1 -WithWallpaperServer from PowerShell in the extracted folder. It starts a small local server at login. In Lively, paste http://localhost:8765/wallpaper.html into the Add Wallpaper box instead of browsing for a file.

Make it yours

Open the settings window to choose the map (dark, dark without labels, satellite, terrain), what colour means, kilometres or miles, how many runners per area, replay speed, and which overlays to show. Changes apply the next time it starts.

Help

The wallpaper says "No runs to show yet"

Open the settings and connect Strava. If you already did, click Full resync.

Strava says the redirect or callback is invalid

In your Strava API app, Authorization Callback Domain must be exactly localhost. Port 53682 must also be free during sign-in.

The map is blank or shows an error

The map tiles need an internet connection (including in the wallpaper). If you're offline or a style is blocked, pick another map style in settings.

Only some activities show up

Only runs (road and trail) that have a GPS route are shown. Treadmill and manually entered runs have no route to draw.

Can I also use it as a screensaver?

Yes. Run .\Install.ps1 -WithScreensaver from PowerShell in the extracted folder. It sets the screensaver for your user and starts after 5 minutes idle (add -TimeoutMinutes 10 to change that).

How do I uninstall?

Double-click Uninstall.cmd in the extracted folder. It removes the app, the screensaver setting (if you added it) and the optional server startup entry. To also delete your saved credentials and runs, delete %APPDATA%\strava-screensaver.
