Strava Screensaver
==================
1. Double-click Install.cmd (Windows may show a SmartScreen warning: More info > Run anyway).
2. In the settings window, follow the steps to create a Strava API app and connect.
3. Wallpaper: install Lively Wallpaper, Add Wallpaper > Browse, pick
   %APPDATA%\strava-screensaver\wallpaper\index.html (no server needed).
   Optional always-live server: Install.ps1 -WithWallpaperServer
   Optional screensaver too:    Install.ps1 -WithScreensaver

Uninstall.cmd removes everything. Full guide: open index.html next to this zip.
